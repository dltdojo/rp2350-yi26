# 檔案即身分

- **日期:** 2026 年 8 月 23 日
- **語言:** 正體中文
- **對應進度:** exp175 – exp179,共 78 個實驗

---

當我們在瀏覽器裡看著自製的 FIDO2 安全金鑰順利登入時,我們必須面對一個一直被寫在 README 裡、卻一直沒被真正攻擊過的事實:

> **這顆安全金鑰的秘密,完全來自寫死在程式碼裡的 32 位元組常數。**

這意味著什麼?exp175 給出了一個直白而殘酷的答案:

**只要有人拿到了你的 `.uf2` 韌體檔案,他不需要拿到你的板子,他就能在自己的電腦上偽造出你這顆安全金鑰的一切憑證與登入斷言。**

## 離線偽造與殘留的記憶

exp175 撰寫了一支名為 `forge.py` 的離線腳本。它直接讀取 exp174 編譯出來的 `.uf2` 檔案,還原記憶體佈局並抓出裝置秘密,接著直接在電腦上計算出合法的 Credential ID 與私鑰,簽署 WebAuthn 斷言,並將使用者在場 (User Presence) 旗標強制設為 1。

主機端的驗證器在不知情的情況下,驗證通過了這份完全在純軟體中捏造出來的斷言。

這個實驗還揭露了兩個常見的認知陷阱:

第一,UF2 檔案是以 512 位元組為區塊打包的。用普通的 `grep` 去搜尋二進位檔案裡的秘密字串,很可能會因為字串剛好跨越區塊邊界而搜尋落空。看著 grep 找不到就以為金鑰被隱藏了,只是被檔案結構騙了。

第二,在真機硬體上,我們把板子先燒錄成完全無關的 exp103 閃燈程式,再重新燒回 exp174。當初註冊的網站依然能順利登入 —— 只要檔案裡的秘密沒變,重新燒錄抹除記憶體只是自我安慰,身分永遠跟著檔案走。

要想斬斷這個威脅,唯一的解法是讓金鑰「不來自二進位檔案」—— 它可以來自一次性燒斷的硬體安全熔絲 (Secure Lock),或是來自晶片本身的物理不可複製特性 (PUF)。

## 當手刻韌體遇見商業產品與現成框架

有了完整的自製金鑰,我們將它與市場上的成熟方案進行了橫向對比:

在 **exp176** 中,我們將自製金鑰與商業級的 Yubico Security Key 進行比對。14 項功能差異中,有 10 項是純粹的軟體程式碼 (如常駐金鑰 resident key、PIN 碼保護、Ed25519 演算法等),板子只要繼續寫程式就能追上。但有 1 項差異是微控制器永遠無法自己補足的:**由大廠原廠燒錄並背書的 AAGUID 與認證憑證鏈**。

在 **exp177** 中,我們測試了用 C 語言和 Pico SDK 開發的開源實作 `pico-fido`。它確實實現了上述 10 項功能中的 9 項,但在細節上給了我們意外的驚喜:它宣稱了真實的 Yubico AAGUID 卻沒有憑證鏈背書;而且在註冊流程中,它完全不等待使用者觸碰按鈕,就直接發送了帶有 `UP=1` 的憑證。

在 **exp178** 中,我們在主機端引入了 Google 的 OpenSK Rust 框架。我們只花了 25 個轉接方法就滿足了 OpenSK 的 43 個 trait 簽名需求,但量測出來的代價是:**光是 OpenSK 的核心引擎就佔用了 121 KiB 的 Flash** —— 這是 exp174 整份韌體 (包含完整 USB 堆疊) 的 1.6 倍,直接衝破了 64 KiB 的 A/B 更新分割區上限。

## 身分之路的曙光:開機未清零的矽晶片

如果不想把金鑰寫在檔案裡,又不想永久燒斷硬體熔絲,最後一條路就是讓金鑰「由矽晶片天生的物理特性即時決定」。

SRAM 物理不可複製函數 (SRAM PUF) 的前提是:微控制器在通電開機時,每個 SRAM 記憶體單元會因為製程微小差異而傾向於偏向 0 或 1。但過去的社群文獻曾斷言:「RP2350 在開機時會把 SRAM 全部清零,因此無法做 SRAM PUF。」

exp179 對這個斷言發起了挑戰。

我們把 USB 傳輸線拔掉、重新插上 (真正的 Cold Boot),並在開機的第一瞬間讀取 SRAM:

```
.uninit 區段: 50.5% 的 1 位元分佈
0x2007_C000 區段: 51.2% 的 1 位元分佈
Bank 8 區段: 51.0% 的 1 位元分佈
全晶片 520 KB 的 130 個 4 KB 區塊中, 沒有任何一個區塊是全零!
```

那過去文獻量到的「全零」究竟是怎麼來的?

答案在於**燒錄路徑**:如果是透過燒錄工具 (`yi26 flash` 或 openocd) 寫入韌體並重開機,燒錄流程會在開機前將 130 個區塊中的 127 個主動清零。

過去的測量是對著「剛燒錄完的板子」進行的,並把燒錄工具的行為誤當成了晶片通電的物理定律。

拔掉傳輸線,通電歸來,RP2350 的 SRAM 完好地保留了豐富的物理隨機分佈。這扇被謠傳鎖上的大門,在真機測量面前被重新推開了。
