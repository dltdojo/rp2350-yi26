What the board does with your bytes is the firmware's business. Every firmware here has an OUT endpoint — exp115's descriptor tree shows it — but they do not agree on what arriving bytes mean. exp118 prints a hex dump of them, exp127 treats \x01 and \x00 as commands and refuses everything else, and the ones before exp118 never read the endpoint at all: the bytes arrive, are never collected, and nothing is printed. That last case looks exactly like this page being broken, and is not.

On Linux, run yi26 detach first. The kernel's cdc_acm driver owns these interfaces and an interface has exactly one owner.
