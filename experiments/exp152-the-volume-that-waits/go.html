Open the board

Tap this. Do not type it — a phone's address bar will search for it instead, which is why this file exists.

http://yi26.local/

The board must be plugged in, and the phone must be sharing its connection with it: Settings → Network & internet → Hotspot & tethering → Ethernet tethering. That switch is greyed out until a device is attached.

If it does not open

This site can't be reached — yi26.local's server IP address could not be found
The name did not resolve. Either the board has no address yet — give it ten seconds after plugging in — or this browser does not do .local lookups. Android has since 2021, Chrome's address bar since Android 12.
ERR_TIMED_OUT
The name resolved and the packets went nowhere. That is routing, not naming: check that Ethernet tethering is actually on.
Nothing happens at all
Some browsers refuse to follow an http:// link from a page opened out of the Files app. Use the box below, which navigates rather than fetching.
