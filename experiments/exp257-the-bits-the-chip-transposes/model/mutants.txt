# exp257 — wrong versions of lean/Rv32/PmpChip.lean, each a way to misread what the RP2350's PMP does with a write
# or an access. privrun builds every one. What refuses them is model/mutants.py: the differential's cases, answered
# again by the wrong model, and held to the true model's answers -- which are the two cores'.
#
# PmpChip.lean holds the model and no theorem about it, and privrun does not import PmpBridge.lean, whose theorems a
# wrong model breaks: what is built is the wrong model and only that. The grain is Priv.lean's `decodeNapotRange`,
# the model's and the chip's alike.
#
# Two misreadings are not here, because no case can tell them apart: PMPCFGM0 binding M-mode to a hardwired region,
# and a hardwired region over other addresses. The hardwired regions match only where the testbench has no memory,
# and there a bus fault and a PMP fault report the same mcause. probes/probes.py reads their registers instead.
#
