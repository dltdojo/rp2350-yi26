On Linux, run yi26 detach first. The kernel's cdc_acm driver owns these interfaces — that is what /dev/ttyACM0 is — and an interface has exactly one owner. Chrome's WebUSB does not take it away for you, so claiming fails until something else does. yi26 attach gives it back; so does replugging, or flashing anything.

While detached there is no serial port, so yi26 log and every terminal program stop seeing the board. Flashing still works — yi26 bootsel sends the same 1200-baud request over a control transfer when there is no port to set a baud rate on.
