exp154 — somewhere to put a key

Every OTP row on this chip, asked and drawn. Nothing here writes.

Plug the board in, then press Connect. The survey starts about three seconds after the board boots and repeats its summary every ten seconds, so it does not matter if you arrive late.
This page needs Chrome or Edge — WebUSB is Chromium-only. On Linux the kernel's cdc_acm driver owns these interfaces until you run yi26 detach; an interface has exactly one owner.
