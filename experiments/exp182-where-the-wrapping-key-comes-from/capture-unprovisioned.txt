# The trade, measured both ways rather than argued:
#
#   0x27 CTAP2_ERR_OPERATION_DENIED -> fido2-cred: FIDO_ERR_OPERATION_DENIED
#        a standard code a client understands — and the same one this firmware
#        returns when nobody pressed the button. Two facts, one number, which is
#        exactly what exp173 spent an experiment on.
#
#   0xF0 vendor                      -> fido2-cred: FIDO_ERR_UNKNOWN
#        distinguishable, and opaque. The client is told 'this is not a standard
#        refusal', and the device says the rest on its LED and in its log.
#
# CTAP 2.1 has no status for 'I have no key material yet', so neither is clean.
# This build takes the second: a number that means ask, over one that means
# something else.
